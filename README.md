# 🌐 Lab 2 - HTML5 y CSS3

Segunda práctica orientada al aprendizaje y aplicación de conceptos fundamentales de **HTML5 y CSS3**, realizada por **Marcos Navarro**.

En este repositorio se incluyen diferentes ejercicios relacionados con la creación de páginas web estructuradas, el uso de tablas HTML, hipervínculos, elementos semánticos y la aplicación de estilos mediante CSS.

## 📋 Descripción

El objetivo de este laboratorio es desarrollar conocimientos básicos para la creación y presentación de páginas web utilizando **HTML5 y CSS3**.

Durante la práctica se trabajan diferentes elementos y técnicas, entre ellas:

* Configuración de documentos HTML5 mediante la etiqueta `<head>`.
* Uso de metadatos como `charset="UTF-8"` y `viewport`.
* Utilización de elementos semánticos como `<section>` y `<footer>`.
* Creación y organización de tablas mediante `<table>`, `<tr>`, `<td>` y `<th>`.
* Implementación de hipervínculos mediante la etiqueta `<a>`.
* Uso de atributos como `href`, `target="_blank"` y `rel="noopener"`.
* Creación de hojas de estilos CSS externas.
* Aplicación de selectores de etiqueta, clase e identificador.
* Uso de selectores descendientes y selectores hijo.
* Aplicación de propiedades CSS para modificar la presentación de las páginas.

Estos contenidos permiten comprender cómo se puede separar la **estructura de una página HTML** de su **presentación visual mediante CSS**.

## 🎯 Objetivos

### Objetivo general

Desarrollar competencias técnicas para la creación de páginas web estructuradas y profesionales utilizando metadatos, elementos semánticos de HTML5, tablas y hojas de estilo CSS modulares.

### Objetivos específicos

* Configurar correctamente la cabecera de un documento HTML5.
* Integrar metadatos de codificación y responsividad.
* Diseñar páginas utilizando bloques semánticos.
* Crear tablas para organizar información.
* Incorporar enlaces externos de forma segura.
* Aplicar selectores de clase e identificadores mediante CSS.
* Controlar la presentación visual de elementos específicos de una página.

## 📁 Estructura del repositorio

| Archivo | Descripción |
|---|---|
| `tabla1.html` | Primer ejercicio de tablas HTML, utilizando las etiquetas `<table>`, `<tr>` y `<td>` para organizar información. |
| `tabla2.html` | Segundo ejercicio de tablas HTML, incorporando encabezados mediante `<th>` y diferentes estilos para mejorar la presentación de la tabla. |

## 🛠️ Tecnologías utilizadas

### HTML5 🌐

Utilizado para crear la estructura y organización de las páginas web, incluyendo tablas, enlaces y elementos semánticos.

### CSS3 🎨

Utilizado para controlar la apariencia visual de los elementos HTML mediante diferentes selectores y propiedades de estilo.

## 💻 Requisitos

Para realizar y visualizar correctamente los ejercicios se necesita:

* Un navegador web actualizado.
* Un editor de código, como **Visual Studio Code**.
* Conocimientos básicos de HTML y CSS.

No es necesario utilizar un servidor web para ejecutar los ejercicios básicos de este laboratorio, ya que los archivos HTML pueden abrirse directamente desde el navegador.
